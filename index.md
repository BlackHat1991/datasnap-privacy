# DataSnap Privacy Policy

**Effective date:** October 10, 2026

## 1. Overview

DataSnap is a browser extension that helps users extract structured information from webpages and export or copy it as CSV or JSON.

DataSnap is designed with a privacy-first approach. Its core extraction and export functionality processes webpage content locally in the user's browser.

## 2. Information Processed

When a user invokes DataSnap, the extension may process information from the active webpage, including:

- Tables and their rows and columns
- Lists and repeating content blocks
- Text and other structured information needed to create an extraction preview

The content of a webpage may contain personal, confidential, or sensitive information. DataSnap processes content selected by the user to provide its extraction functionality.

## 3. How Information Is Used

Information processed by DataSnap is used only to:

- Detect structured content on the active webpage
- Display extracted information for user review
- Allow users to export data as CSV or JSON
- Allow users to copy extracted data to their clipboard
- Complete the user-initiated region-selection workflow

## 4. Local Processing and Data Sharing

DataSnap's core functionality is designed to operate locally in the browser.

- DataSnap does not require a DataSnap account or backend service.
- Extracted webpage content is not sent to a DataSnap server.
- DataSnap does not use third-party analytics services in its intended V1 design.
- DataSnap does not sell users' data or share extracted webpage content with third parties.
- DataSnap does not use extracted content for advertising.

## 5. Storage and Retention

DataSnap may use browser extension storage for temporary state needed to complete its extraction and region-selection workflows.

DataSnap does not maintain a cloud database of extracted webpage content. Users control where they save exported files and where they paste copied information.

## 6. Permissions

DataSnap requests the following browser permissions:

- **activeTab:** To access the active webpage after the user invokes the extension.
- **scripting:** To run extraction logic on the user-selected webpage.
- **storage:** To retain temporary extension state required for the extraction workflow.

These permissions support DataSnap's user-facing extraction and export features.

## 7. User Control

Users choose when to invoke DataSnap and which extracted information to export or copy. Users should avoid extracting or sharing information unless they are authorized to do so.

## 8. Children's Privacy

DataSnap is a general-purpose productivity tool and is not designed specifically for children. It does not knowingly collect children's personal information through a DataSnap server.

## 9. Changes to This Policy

This policy may be updated when DataSnap's functionality or data practices change. Updates will be published on this page with a revised effective date where appropriate.
